【核心原理】
用你 ChatGPT 网页端用不完的普通聊天额度，直接操控你电脑本地的文件与终端！
0 公网穿透、0 域名配置、0 延迟，纯走本地 127.0.0.1 闭环。

--------------------------------------------------------------------------------
【⚡ 真实血泪避坑指南（99% 的人卡住都在这里，必看！）】
--------------------------------------------------------------------------------
⚠️ 雷点 1：Edge 浏览器的「允许用户脚本」开关没开！（头号大坑）
   很多朋友油猴装好了、脚本也保存了，但刷新网页右下角永远空空如也，就是卡在这里！
   • 原因：微软 Edge 最新的安全策略默认静默拦截所有油猴脚本。
   • 解决：在 Edge 地址栏打开：edge://extensions/
     找到「篡改猴 (Tampermonkey)」点击「详细信息」，往下滑找到【允许用户脚本】
     那个绿色开关，必须手动打开它！打开后再刷新 chatgpt.com 绿灯秒出！

⚠️ 雷点 2：千万别走错窗口！是在【浏览器网页端】，不是【Windows 桌面端软件】！
   • 很多人电脑上装了 ChatGPT 桌面客户端（ChatGPT.exe），点开桌面软件纳闷
     “为什么右下角没有绿灯？”——因为油猴插件是装在 Edge/Chrome 浏览器里的！
   • 独立的 Windows 客户端根本不支持浏览器扩展。
   • 必须在 Edge 或 Chrome 浏览器标签页里打开：https://chatgpt.com/ ！

⚠️ 雷点 3：黑窗口只要看到 🐳 就算成功，放后台别关！
   • 双击 start_bridge.cmd 后，只要看到：
     “🐳 ChatGPT Web <-> Local Codex Bridge ... 等待浏览器油猴脚本连接并下发任务...”
     就代表本地执行器已经 100% 准备就绪，最小化放后台即可，关掉它本地就断连了。

⚠️ 雷点 4：访问 chatgpt.com 还是需要正常开代理的！
   • 打开 chatgpt.com 官网聊天需要你的正常代理软件（如 XSUS）；
   • 但网页跟本地工作区之间的通信（127.0.0.1:9090）是纯本机内网回环，
     绝对不经过代理、不消耗任何节点流量、不需要公网穿透！

--------------------------------------------------------------------------------
【第一步：启动本地执行器（只需双击）】
--------------------------------------------------------------------------------
在当前文件夹里，直接双击运行：
👉 start_bridge.cmd

看到弹出黑窗口显示“等待浏览器油猴脚本连接”即可，最小化放后台。

--------------------------------------------------------------------------------
【第二步：安装浏览器油猴脚本（只需配置一次）】
--------------------------------------------------------------------------------
1. 打开 Edge / Chrome 浏览器，应用商店搜索并安装「篡改猴 (Tampermonkey)」。
2. （Edge 必做）：进入 edge://extensions/ ➔ 篡改猴详情 ➔ 开启【允许用户脚本】开关！
3. 打开当前文件夹下的【ChatGPT-Codex-Bridge.user.js】文件（用记事本打开）。
4. 全选复制里面的全部 JavaScript 代码。
5. 点击浏览器右上角油猴图标 ➔「添加新脚本」➔ 删掉默认文字 ➔ 粘贴进去 ➔ Ctrl+S 保存。
6. 打开或刷新 https://chatgpt.com/，你会发现网页右下角亮起悬浮小胶囊：
   👉 🟢 Codex 本地桥: 已连通 (工作区就绪)

--------------------------------------------------------------------------------
【第三步：开工聊天（日常使用）】
--------------------------------------------------------------------------------
1. 在 chatgpt.com 网页端新建一个聊天会话。
2. 打开当前文件夹下的【PROMPT.txt】，复制里面的开工提示词发给 ChatGPT。
3. 从这一刻起，ChatGPT 就会自动变成一个全自主编码 Agent：
   • 它想读文件时 ➔ 会输出 tool:read ➔ 本地秒级读完自动发回给它；
   • 它想改代码时 ➔ 会输出 tool:write ➔ 本地自动写入文件并回传成功；
   • 它想测试时   ➔ 会输出 tool:exec  ➔ 本地自动在终端跑命令并回传输出结果；
   • 你只需要坐在屏幕前看着它自动递归迭代，直到代码在本地彻底写好跑通！

--------------------------------------------------------------------------------
【进阶问答】
--------------------------------------------------------------------------------
Q: 我想换别的工作区目录（比如改别的项目）怎么办？
A: 直接把当前文件夹里的全部文件复制到你的新项目目录里，
   然后双击运行那里的 start_bridge.cmd 即可（它会自动把所在文件夹作为工作区）。

Q: 如果不想让它全自动跑，想每一步人工看一眼再执行？
A: 在 chatgpt.com 网页右下角的控制胶囊里，把【自动执行并回传】取消勾选，
   它每输出一个动作就会等待你点击确认后再执行。
